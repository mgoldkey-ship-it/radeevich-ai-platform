**Проект:** Клиент-серверная система Telegram Mini App & Web с real-time AI-ассистентом  
**Автор:** Юрий Радеевич  
**Стек инструментов:** AI Agent Architecture (Claude Code / Arena Agent / Cursor), Groq Inference Cloud, Node.js Serverless.

---

## 1. Первоначальный системный промпт проекта

> «Спроектируй и разработай масштабируемую клиент-серверную систему:
> 1. Фронтенд: адаптивный Web-клиент и нативный Telegram Mini App с плавающим AI-виджетом диалога реального времени.
> 2. Бэкенд: Serverless API на Node.js с маршрутизацией запросов, управлением сессиями и подключением LLM через Groq API.
> 3. Требования: сверхбыстрый отклик (<1 сек), сохранение контекста, фильтрация prompt-injection и защита от нецелевого расхода токенов.»

## 2. Использованные AI-инструменты

- **Разработка и кодогенерация:** AI Agent Mode (Claude 3.5 Sonnet / Claude 3.7) в связке с Cursor CLI для генерации кода, компонентной сборки и автоматического рефакторинга.
- **Инференс в продакшене:** Groq Cloud API с ультра-быстрым инференсом на LPU (`qwen/qwen-2.5-32b` / `qwen3.8-27b`) со средней задержкой ~400-800 мс.
- **Инструменты контроля качества:** Playwright (автоматизированные скриншоты и E2E тестирование в мобильных и десктопных вьюпортах).

## 4. Стратегии оптимизации токенов и эффективности (Token Optimization)

1. **Локальный Pre-Flight фильтр безопасности (Zero-Token Security Guard):**
   - Все входящие сообщения проходят локальную валидацию регулярными выражениями и эвристиками на уровне Serverless функции (`bot.js`) до обращения к LLM.
   - Попытки prompt injection, взлома системного промпта или извлечения API-ключей мгновенно перехватываются и получают заготовленный статический ответ.
   - **Эффект:** 100% экономия токенов на аномальных и вредоносных запросах пользователей.

2. **Скользящее окно контекста (Sliding Window History Pruning):**
   - Вместо бесконечной отправки всей истории переписки сервер передает в LLM только последние 4–6 реплик диалога, достаточных для поддержания связности.
   - **Эффект:** Входной контекст зафиксирован на уровне ~500–800 токенов вместо лавинообразного роста до 10k+ токенов.

3. **Компактный системный промпт без избыточного многословия:**
   - Системный промпт структурирован тезисно, с четкими ролевыми маркерами и правилами форматирования, исключая паразитный boilerplate.
   - **Эффект:** Экономия ~40% токенов на каждом обращении к AI-ассистенту.

4. **Выбор модели по соотношению цена / скорость / качество:**
   - Использование специализированных моделей семейства Qwen 2.5 / Llama 3 на инфраструктуре Groq вместо тяжеловесных closed-source моделей общего назначения.
   - **Эффект:** Снижение себестоимости одного диалога более чем в 10 раз при сохранении качества консультаций.
