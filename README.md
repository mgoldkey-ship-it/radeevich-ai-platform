# Telegram Mini App & Web AI Client-Server Platform

> Высокопроизводительная клиент-серверная система со встроенным real-time AI-ассистентом на базе Serverless архитектуры и LLM Groq Cloud API.  
> Разработано в парадигме **AI-Assisted Engineering**.

## ⚡ Ключевые возможности

1. **Кроссплатформенность «из коробки»:**  
   Единый фронтенд работает как самостоятельный веб-сайт и как бесшовное нативное приложение внутри Telegram (Mini App).
2. **Встроенный виджет AI-ассистента:**  
   Плавающий виджет с плавной анимацией, предзаготовленными чипсами быстрых вопросов и поддержкой свободного ввода.
3. **Безопасность и оптимизация бюджета (Zero-Token Guard):**  
   Атаки типа Prompt Injection, попытки кражи системных промптов или API-ключей блокируются на сервере до вызова LLM. Это гарантирует нулевой расход токенов на спам и хакерские попытки.
4. **Контроль длины контекста:**  
   История переписки динамически обрезается до фиксированного окна, предотвращая квадратичный рост затрат на контекст.
5. **Высокая скорость (Sub-Second SLA):**  
   Использование специализированных чипов Groq LPU обеспечивает генерацию ответа за доли секунды.

## 🛠 Технологический стек

- **Frontend:** Vanilla JavaScript (ES6+), HTML5, CSS3 Grid/Flexbox, Telegram WebApp SDK, SVG иконки.
- **Backend:** Node.js (Vercel Serverless Functions), REST API.
- **AI & LLM:** Groq Cloud API (`qwen/qwen-2.5-32b` / `qwen3.8-27b`), Prompt Engineering, Context Sliding Window.
- **DevOps & QA:** Git, Vercel CI/CD, Playwright E2E Testing, DNS Cloudflare/RU-CENTER.

## 🚀 Локальный запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/radeevich-ai-client-server.git
   cd radeevich-ai-client-server
   ```

2. Скопируйте переменные окружения:
   ```bash
   cp .env.example .env
   ```
   Укажите ваш `GROQ_API_KEY` и `BOT_TOKEN`.

3. Запустите локальный сервер:
   ```bash
   node serve.js
   ```

4. Откройте `http://localhost:3000` в браузере.
